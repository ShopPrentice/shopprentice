# Voronoi

**Source:** [hanskellner/Fusion360Voronoi](https://github.com/hanskellner/Fusion360Voronoi)
**License:** MIT
**Author:** Hans Kellner

## What It Demonstrates

- **SVG import** into sketch (`sketch.importSVG()`)
- HTML Palette UI with bidirectional Python-JavaScript communication
- Profile loop analysis (`profile.profileLoops`, curve evaluators)
- Selection command input with sketch/profile filters
- Bounding box computation for sketch profiles
- `curve.isFixed` manipulation for constraint toggling

## Parameters

| Parameter | Description |
|-----------|-------------|
| Sketch/Face | Target sketch or planar face |
| Cell Count | Number of Voronoi cells |
| Scale | Pattern scale factor |
| Style | Edge style (line, curve) |

## Key Patterns for `/woodworking`

- **SVG import**: Bringing in decorative patterns, logos, or CNC toolpath profiles
- **Profile analysis**: Iterating sketch profiles and their loops for selective extrusion
- **Decorative patterns**: Cut patterns for panels, screens, or decorative inserts
