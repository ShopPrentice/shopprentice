# Side Table / Nightstand

A parametric modern side table — 22"L x 16"W x 24"H with single dovetailed drawer. No front apron — the drawer front acts as the visible face.

```

Build a modern nightstand: 22"L x 16"W x 24"H, single drawer,
dovetailed drawer box, square legs. All parametric.
```

**Script:** [`side_table.py`](side_table.py) — 13 bodies (4 legs, 3 aprons, top, 5 drawer bodies). Uses `dovetailed_drawer` template.
